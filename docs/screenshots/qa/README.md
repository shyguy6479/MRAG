# Visual QA evidence

Reviewed on 5 October 2026 in the local preview browser.

The filename prefix is the tested viewport width: 1280×800, 1440×900,
1728×1117, 1920×1080, 390×844, or 1024×768. Wide full-page images can be
taller than their viewport; scrollbar space may reduce captured content width.

The nine major views have screenshots at all four requested desktop sizes and
phone size. Additional captures cover navigation, sidebar collapse, upload,
request waterfalls and the tablet/mobile evidence sheets. Metrics and response
content came from the local API and stored authored-fixture benchmark runs.

See [interface-design.md](../../interface-design.md) for behavior and limits.
